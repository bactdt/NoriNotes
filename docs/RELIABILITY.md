# 可靠性要求

1. **数据安全高于一切**：写入必须 `.atomic`；任何解析失败不得覆盖原文件（先备份 `.corrupt`）。
2. **防抖保存**：编辑后 0.3s 落盘；应用退出（`willTerminateNotification`）时强制落盘。
3. **防抖令牌模式**：新输入使旧定时任务失效，禁止并发写盘。
4. **删除需确认**：不可恢复操作必须二次确认。
5. **密钥生命周期**：加密密钥仅存内存字典，锁定即清除；持久化前重新封存明文内容。

## 可验证断言（性能）

- 编辑器输入延迟：单次按键到文本呈现 < 16ms（60fps 不掉帧），大文档（≥1 万字）同样成立
- 保存耗时：防抖触发后的写盘在后台可接受，但不得阻塞主线程事件循环
- 启动：1 万字 × 100 篇笔记规模下，启动到首帧 < 800ms
