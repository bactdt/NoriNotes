# 安全要求

1. **密码保护**：PBKDF2-HMAC-SHA256（160,000 轮，16 字节随机盐 `SecRandomCopyBytes`）派生密钥，AES-GCM 认证加密。
2. **密钥不落盘**：仅存于 `@MainActor` 内存字典；应用退出即消失。
3. **密码明文不持久化**：UI 必须明示"忘记密码无法恢复"。
4. **锁定状态**：锁定笔记在内存与磁盘上只有密文；列表/搜索不得泄露其内容。
5. **无网络行为**：应用不发起任何网络请求（同步功能被排除后，此点成为安全承诺）。
6. **密码学实现冻结**：改动前必须征得用户确认（见 `docs/exec-plans/tech-debt-tracker.md` TD-1）。
