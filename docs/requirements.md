# 需求文档（Nori Notes）

> 来源：用户于 2026-10-13 在对话中确认（§3.2 复述确认记录）。本文件是需求的唯一记录点。

## 产品定位

macOS 桌面 Markdown 笔记应用，延续「安静写作角落」的产品气质：三栏布局（筛选 / 列表 / 编辑器）、四套主题、自动保存到本机。

## 功能需求

1. **Markdown 笔记**（本次核心新增）
   - 正文以 Markdown 源码存储
   - 编辑形态：**所见即所得**（用户明确选择，非源码+预览切换的降级方案）
   - 实现策略：基于 NSTextView 的实时样式渲染（live-preview 式 WYSIWYG），保证大文档性能
2. **笔记管理**：置顶、归档、标签（逗号分隔编辑）、按标题/正文/标签搜索
3. **密码保护**：单篇笔记 AES-GCM 加密（PBKDF2 派生密钥），解锁/锁定，密钥仅存内存，密码不可恢复需在 UI 明示
4. **OCR 导入**：图片/PDF → Vision 本机识别 → 追加到当前笔记或新建笔记
5. **导出**：Markdown / HTML / DOCX / PDF / JPG / EPUB 六种格式
6. **外观**：四套主题（羊皮纸/海盐蓝/鼠尾草/暮色）+ 应用标志样式切换

## 明确排除

- **iCloud / CloudKit 同步**：用户确认排除（需要签名团队，CI 无法验证）。架构上保持数据层与 UI 解耦，未来可作为可选模块加入。

## 非功能需求

- **性能优先**（用户明确强调）：编辑器输入不得全文重排，只对被编辑的段落增量重样式；保存走防抖；列表与搜索不做重复计算。
- 数据文件：`~/Library/Application Support/NoriNotes/notebook.json`，原子写入，损坏时先备份再重建。
