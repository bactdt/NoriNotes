# 质量评分

> 按架构层打分并追踪差距。1–5 分，3 分=可用，4 分=健壮，5 分=有测试覆盖的健壮。

| 层/领域 | 分数 | 差距 |
|---|---|---|
| Types（模型/加密） | 4 | 有认证加密与原子写盘；缺单元测试（需 macOS 环境，CI 补） |
| Store（状态/持久化） | 4 | 防抖+退出落盘+损坏备份；缺单元测试 |
| UI（视图/编辑器） | 3 | WYSIWYG 增量重样式是性能关键路径，需人工 + CI 双验证 |
| CI 门禁 | 3 | lint/结构测试/构建已就位；单元测试 job 随测试加入后启用 |
| 文档 | 4 | Day 0 全套就位；随功能演进同步更新 |

## 更新纪律

每完成一个阶段或发现新差距，更新本表；垃圾回收任务（后台扫描）以此为基准发起重构。
